# Introduction to Databases

This repository contains the course material for
 the Introduction to Databases class taught at UCLA.
Each Markdown file under [notes](notes/) simultaneously
 compiles to an interactive notebook (using [codapi](https://codapi.org))
 and a slide deck.
The slides are *not* designed to be shown in class;
 they are meant to be read by the students during review,
 and to provide guidance to the lecturer when they teach.
In fact, the lectures at UCLA do not use slides at all,
 and are taught with blackboards instead.
Building with `make notes` will produce slides with
 speaker notes suggesting how to use the board.

The homework assignments already contain solutions.
This is because they are not graded.
The students are nevertheless motivated to work on
 the homework, because they will take several
 quizzes that depend on the homework -- indeed,
 the assignments frequently introduce concepts
 *not* covered in lecture.
If you'd like to teach a similar class,
 contact [Remy](https://remy.wang) for the quizzes.
