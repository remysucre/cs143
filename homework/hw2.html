The decomposition algorithm shown in class looks for nontrivial FDs X \to Y such that X does not contain a key. This is expensive to implement, as we would have to try each possible pair of X and Y, and there are (2^n)^2 = 2^{2n} many such pairs. Specifically, we would implement the following nested loop:

for xs in powerset(sigma):
  for ys in powerset(sigma):
    if not contains(xs, ys) and not isKey(xs, fds, sigma):
      ...

Instead, we can just look for X s.t. X^+ \neq X and X^+ does not cover all table attributes:

def decompose(R):
  S = attributes of R
  find X s.t. X+ != X & X+ != S
